# AIFactory Hub — Feature Overview

---

## 🎨 AI Media Studio

### Auto Content Factory
- Raw video → auto highlight detection → clips → subtitles → metadata → publish
- Batch processing
- Scheduled publishing
- Multi-platform (YouTube Shorts, Instagram Reels, Telegram)

### Manual Content Factory
- **Image Tools**: Analyze · Edit · Generate · Upscale · Remove background
- **Video Tools**: Generate · Transform · Extend · Style transfer
- **3D Tools**: Object · Avatar · Environment · Volumetric generation
- **Export formats**: PNG · JPG · WEBP · MP4 · WebM · GLB · OBJ · FBX · STL

---

## 📊 Data & Knowledge Studio

- Document ingestion (PDF, DOCX, TXT, CSV, JSON)
- RAG (Retrieval-Augmented Generation) for private knowledge
- Web research with source extraction
- Statistics and data analysis
- Chart generation
- Report generation (Markdown, PDF)

---

## ⚙️ Engineering Studio

- **Code Analysis**: Architecture, dependencies, complexity
- **PCB Analysis**: Component detection, wiring analysis
- **CAD Analysis**: Mechanical component understanding
- **Datasheet Analysis**: Extract specs and compare components
- **Requirements → Architecture** conversion

---

## 🤖 Hamda Agent

- **Project Scaffolding**: Create new projects with structure
- **Code Generation**: Write code from descriptions
- **Refactoring**: Modernize existing code
- **Git Operations**: Commit, branch, merge with meaningful messages
- **Build & Fix**: Run builds, fix compilation errors
- **Documentation**: Generate docs from code
- **Architecture Analysis**: Understand large codebases
- **Codebase RAG**: Query your own code
- **Memory**: Persistent preferences across sessions

**Hook:** *From idea to working project. Plan. Code. Build. Test. Document. Deploy.*

---

## 🔀 Hybrid AI Routing

| Task Complexity | Model |
| :--- | :--- |
| Simple (autocomplete, format) | Local 7B (fast, private) |
| Medium (single-file refactor) | Local 14B or Cloud |
| Complex (multi-file, agent tasks) | Cloud (Gemini) |

All configurable in Settings → Hybrid Routing.
